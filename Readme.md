# Сервис уведомлений Notif-service (тестовый проект)

## Запуск (все команды запускаются в корне приложения):

1. Создаем конфигурационный файл Laravel:
`cp .env.example .env`

2. Разворачиваем контейнеры приложения через Docker compose:
`docker-compose up --build -d`

3. Одной командой запускаем генерацию ключа Laravel и проводим миграции с сидерами (добавляются пользователи и связанные уведомления):
`make run`

### Стек:
`Язык:` `PHP 8.5`
`Фреймворк:` `Laravel 13.x`
`Сервер:` `Nginx`
`База данных:` `PostgreSQL 18.4`
`Очереди:` `Redis + Horizon`
`Контейнеризация:` `Docker, Docker compose`
`Тестирование:` `PHPUnit`
`Статический анализ:` `PHPStan (Уровень 5)`
`Code style fixer:` `pint`

#### Архитектурное решение: Монолит с элементами SOA
Проект реализован как монолитное приложение — весь код находится в одном репозитории и 
разворачивается как единое целое через Docker Compose. Это решение принято для простоты 
разработки и развертывания.

Сам код организован по принципу `Service-Oriented Architecture (SOA)`:
- `Сервисы:` основная бизнес-логика вынесена в отдельные сервисы (`NotificationService`, `ReportService`)
- `DTO:` четкая типизация данных между слоями
- `Job:` асинхронная обработка запроса (очереди)
